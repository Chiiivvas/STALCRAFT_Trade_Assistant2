# Патч к stalcraft_trade_assistant_v2.2

Файл `PATCH_seed_icons_and_copy.diff` содержит изменения, подготовленные для архива `stalcraft_trade_assistant_v2.2.zip`.

Патч исправляет:
- повторную обрезку seed-иконок 72×74 px в matcher (эталоны пыли/солевика и других трёх мякотей);
- добавление недостающих стандартных seed-шаблонов в уже существующую SQLite-базу без перезаписи пользовательских цен и шаблонов;
- отображение неизвестных предметов даже при старой настройке hide_unknown_items=true;
- копирование предварительной суммы во время фоновой проверки с предупреждением и раздельным показом предварительной/подтверждённой суммы.

Применение к распакованному проекту:
```bash
git apply PATCH_seed_icons_and_copy.diff
```

Проверка:
- все Python-файлы компилируются;
- pytest в текущей среде зависает/не завершается в доступный лимит времени, поэтому полный прогон не подтверждён;
- проверка на Windows и на живом окне игры ещё не выполнялась.

Это отдельная ветка; main не изменяется автоматически.
